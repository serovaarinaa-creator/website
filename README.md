# arinaserova.com

Многостраничный сайт-портфолио Арины Серовой (дизайн / иллюстрация). Статический сайт на чистом HTML/CSS/JS — без сборки и зависимостей.

## Структура

- `index.html` — главная
- `about.html` — обо мне
- `portfolio.html` — портфолио
- `contact.html` — контакты
- `styles.css`, `script.js` — стили и скрипты
- `404.html` — страница не найдена

## Деплой на Vercel

1. Зайдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. **Add New → Project**, выберите этот репозиторий (`serovaarinaa-creator/website`).
3. Framework Preset — **Other** (статический сайт), Build Command и Output Directory оставьте пустыми (корень репозитория и есть корень сайта).
4. Нажмите **Deploy** — через минуту сайт будет доступен на `*.vercel.app`.

## Подключение домена arinaserova.com

1. В проекте на Vercel откройте **Settings → Domains** и добавьте `arinaserova.com` (и при желании `www.arinaserova.com`).
2. Vercel покажет DNS-записи, которые нужно добавить у регистратора домена:
   - для корневого домена (`arinaserova.com`) — обычно `A`-запись на `76.76.21.21`;
   - для `www.arinaserova.com` — `CNAME`-запись на `cname.vercel-dns.com`.
   (Точные значения смотрите в интерфейсе Vercel — они могут обновляться.)
3. Сохраните записи в панели управления доменом и подождите обновления DNS (обычно от нескольких минут до пары часов).
4. Vercel автоматически выпустит SSL-сертификат после подтверждения домена.

После этого каждый `git push` в основную ветку репозитория будет автоматически деплоить обновлённый сайт.
